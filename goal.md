# Goal

## Project
pint — a python project.

## Description
Pint is a Python library for defining, operating, and manipulating physical quantities — the product of a numerical value and a unit of measurement. It provides a unit registry that loads unit definitions from text files, supports arithmetic operations between quantities with automatic unit conversion, dimensional analysis, unit parsing, and rich formatting (plain text, LaTeX, HTML). Key features include: prefix handling (SI and binary), derived dimensions, temperature offset units, physical constants, measurement uncertainty support, and comprehensive error handling for incompatible unit operations.

- ~10 test files to write
- Reproduce core source code, tests, and configuration covering: unit registry, quantity arithmetic, unit conversion, dimensional analysis, unit definition parsing, formatting, error handling, measurement uncertainty, and temperature/offset unit support
